# Исходные файлы (скачаны с официальных сайтов, без изменений)

## `belstat_export/`, `belstat_import/` — Белстат
«Экспорт и импорт товаров (6 знаков ТН ВЭД ЕАЭС)», раздел II «Продукты растительного происхождения», годовые данные.
Имя файла = отчётный год (в файле также данные предыдущего года). В формате xls доступны 2018–2021 гг., за более ранние годы — PDF.
- Файлы за 2012 г. и 2008–2009 импорта отсутствуют; значения импорта за эти годы в расчёте не используются (2008) или интерполируются (2012).

## `nbrb_fx/` — Национальный банк Республики Беларусь
Официальный курс белорусского рубля по отношению к иностранным валютам, ежедневно, по годам 2008–2024 (`YYYY_day_ru.xls`).
Из них скриптом `src/fx_parse.py` получен `data/processed/fx_usd_daily.csv`.
